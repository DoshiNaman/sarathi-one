# Models

`toy-car.glb` — "Toy Car" by Guido Odendahl, materials by Eric Chadwick.
Public domain (CC0). From the Khronos glTF-Sample-Models repository:
https://github.com/KhronosGroup/glTF-Sample-Models/tree/main/2.0/ToyCar

Held here rather than hotlinked so the demo does not depend on GitHub being up,
and so nothing about this screen needs a third-party request at runtime.

It is a generic toy car on purpose. Real car bodies are trademarked designs and
the free models of them carry unclear licences — not something to ship in a
judged entry. The UI says "illustration only" for the same reason.
